# Deliverable

Most rewrites of a graded document come from drafting before reading what is graded. These
steps run in order.

## Before drafting
1. **Read the spec, template or rubric first.** Open the assignment sheet or grading table
   before writing anything. Say the grading weights back, so the effort goes where the marks
   are.
2. **Use the rubric's literal phrases as the outline.** If it asks you to "identify the
   main risks and how you will reduce them", that phrase is a heading. Don't invent a better structure than the one
   being graded.
3. **Agree the length and format once.** Ask for a target (words, paragraphs or pages) and
   whether tables are wanted, and state it back. Never draft long and trim again and again.
4. **Write only the sections asked for.**

## While drafting
5. **Source every outside fact when you write it.** Competitor numbers, prices, limits, specs
   and market sizes get a link and the date checked. Your own earlier claim is not a source,
   even after it has been repeated in several files. Search for direct substitutes, not only
   the categories you already had in mind.
6. **Let the destination set the register.** A report gets compact paragraphs in plain words.
   Run the `writing-check` skill on the draft. Without it, reread for dashes inside sentences,
   filler and stock phrases.

## Before handing it back
7. **Check the document against itself.** A number or claim in one section must not
   contradict another. If they clash, say which one to change.
8. **List what is still blank and who owns it.** No quiet placeholders. Flag any teammate's
   work that was cut, so nobody finds it missing.
9. **Verify each paste into a shared document landed.** Open the document and look; a failed
   paste can look like a successful one.

## Done when
The document matches the rubric's structure and the agreed length, every outside fact has a
source, no section contradicts another, and blanks are listed with owners.
